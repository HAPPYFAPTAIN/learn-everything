# 学习 Agent 的执行边界

当前实现有三条协作链路，全部位于 `learning_ext/`，不修改 Kotaemon 底座。

## 动手学对话

`pages/coach.py → agent/runtime.py → llm/client.py → agent/tools.py`

`app.py` 的动手学入口注册 `CoachPage`。历史 `CoachLessonPage` 只是固定练习演示，不再作为主入口。空白页的三条建议仅填入任务，不触发执行；用户可自由输入其他任务。

对话以流式文本和工具回执显示进展，操作前提供完整参数预览与单步确认。执行期间不能重复提交或清空；新对话重置运行时。上翻阅读时保留位置，可点击「最新进展」返回底部。界面与代码复制组件使用统一明暗主题。

`zcode_core.TurnMachine` 提供从 ZCode 适配的回合状态机和能力判定。模型可以计划、查证和提出动作，执行器负责批准、执行和回执。MCP 工具通过 `mcp_bridge.py` 接入，仍须单次确认。

- 单个回合最多 12 轮模型规划，批准动作后继续累计，不重置预算；上游临时网络错误另有有限重试。
- 每次只批准一个动作；参数摘要和 90 秒有效期绑定批准，拒绝后停止。
- 同一回合中，相同工具、参数与结果出现两次失败或三次成功则暂停。重新输入会开启新回合。
- 工具成功与目标完成分开：非零退出码、结构化错误和 MCP 错误不会记录为成功。
- 大型结构化结果会减少结果条数并标注截断，保持 JSON 可解析。
- 历史压缩保留学习者补充的目标和限制，只裁去较早的工具往返。
- 支持需要 `reasoning_content` 的模型工具往返，该字段只进入模型请求，不展示为回答。空回复、截断或被过滤的回复明确提示；不执行未完整结束的工具调用。
- 执行前日志不可用时不操作；执行后记录失败时保留已返回结果、补全工具历史并暂停，避免失去回执后重复执行。

## 课程行动与电脑引导

`action_learning/service.py → agent/guided_desktop.py → guided_controls.ps1`

课程上下文决定目标，当前行动决定操作范围。先读取 UI Automation 控件，再圈选提示；单独授权后才执行，执行前复核窗口身份、控件身份、位置及状态。

短期观察凭据绑定窗口句柄、进程与创建时间。通用鼠标/键盘操作也必须指定完整窗口标题，避免用户点确认后输入落到本应用。

可读取状态的操作有界核验，不盲目重试。普通按钮的调用返回只能证明请求已发送，回执 `verified=false`；学习者或下一次观察仍需确认实际效果。自绘界面无法识别标准控件时转为文字引导，不猜测坐标。

## 搜索与环境发现

- `environment_agent` 按学习需求规划只读探针；安装登记、开始菜单和 PATH 是线索，版本和可执行能力仍要验证。
- `agent/search.py` 按指定目录和文件名搜索，也提供有行号的原文搜索；限制深度、时间、文件量和读取大小，不跟随目录链接。
- 软件随附官方 Everything 便携版、SDK 与 ES 查询组件。按需启动独立实例，为指定文件夹建立名称索引；ES 支持命名实例，避免连接或关闭用户自行安装的 Everything。索引错误或未准备好时保留原因并回退，不把不可用解释为不存在。打包与生命周期见 `EVERYTHING_INTEGRATION.md`。
- `agent/web_search.py` 对接管理员配置的 SearXNG JSON 接口。`LE_SEARCH_URL` 未配置时明确不可用，不自动选择公共搜索站。网页结果仅为摘要，保留来源，不等于已读全文。
- 文件内容搜索和网络查询沿用确认边界。搜索词使用公开技术信息；搜索结果作为资料，不能改变权限或触发执行。

## 记录与服务器接口

回合阶段、工具参数、执行耗时、结果和批准状态通过 `action_learning.service.Journal` 写入本地 SQLite 日志，沿用密钥脱敏。轨迹有 `session_id / trace_id / turn_id / call_id`，便于定位失败原因。

账户预留入口见 `ACCOUNT_INTEGRATION.md`。现阶段仍是本机单用户；服务器验证器和数据归属接口已定义，但全业务数据隔离迁移完成前不能作为多人服务运行。
