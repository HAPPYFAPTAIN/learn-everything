# 输入文字润色

自然语言输入框旁提供「润色」按钮，使用模型配置页当前启用的模型。只在点击后发送该输入框的文字；不读取其他输入、课程全文、测验参考答案或附件内容。

结果先在入口旁预览，点击「采纳」才写回。不会替用户发送消息、提交作答、保存笔记或执行桌面操作。网页输入支持一次撤销；原文发生修改、切换课程或离开当前输入场景后，旧结果不能再覆盖内容。空内容、禁用或只读输入不发起请求。

## 按用途编排

- 学习目标、背景：整理表达，保留范围、已有能力和限制，不添加期限或学习承诺。
- 问答、当前步骤求助：把问题问得更明确，不回答问题或提供解题线索。
- 笔记、批注：保留自己的理解、口吻与不确定之处，不添加知识或例子。
- 测验、复述、卡片答案：只调整文字，保留原有推理，包括错误或未完成的部分。
- 标题、资料集名称：保持简短，不扩写成段落。
- 任务指令、验收标准、反馈：整理原有要求，不执行指令或添加条件。

输入保留原语言及简繁体。代码块、行内代码、链接和 @ 引用通过占位符保护并核对；数字也会核对。校验失败显示提示并保留原文。润色仍是模型生成的建议，采纳前可以检查预览。

## 覆盖与扩展

`learning_ext/text_polish_ui.py` 的 `FIELDS` 注册 Gradio 自然语言组件，包括首页、路线、工作台、复习、测验、知识问答、全局助教和桌面任务输入。资料库各索引的 `group_name` 自动注册为标题。通过标记原组件接入，不重建输入框，也不替换多模态输入中的附件。

动态 HTML 输入使用 `data-le-polish-kind="note"` 等属性。当前覆盖动手学目标与验收标准、选段自定义改写要求、新建批注和批注编辑。原生桌面练习器通过 `native.py` 调用同一服务，用异步进程等待结果。

密钥、模型 ID、网址字段、搜索框、数字、公式、代码编辑器、删除确认与内部数据桥不参与文字润色。包含代码或链接的自然语言段落可以润色，但保护其中的技术内容。

## 实现与检查

提示词位于 `learning_ext/text_polish/prompts.py`，模型调用通过 `learning_ext.llm.chat`。最大输入为 12000 字符。用户输入和模型返回按数据处理，预览使用纯文本，响应桥转义 HTML；日志只记录种类、长度和结果，不记录原文。

测试覆盖分类隔离、输入校验、提示词边界、受保护内容、失败时保留原文、HTML 转义、前端过期响应与撤销保护。

本轮实际检查了首页目标的润色、采纳和撤销，以及知识问答中保留 `@WebSearch` 的问题改写。动态动手学输入的按钮和配置页排除规则已在浏览器核对；原生窗口已启动并读取控件。原生预览、采纳、修改失效、取消、超时及子进程树清理由不显示窗口的 WPF 行为测试验证。
