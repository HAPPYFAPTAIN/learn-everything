# 学习应用亮色界面改版

日期：2026-10-17

参考：https://design.ricoui.com/ 。已查看首页、工作台及其明暗外观，按用户最后要求，仅实现亮色版本。

## 视觉与布局

- 柔白画布、白色卡片、深灰正文与淡蓝选中态，主操作使用低饱和蓝色。
- 无衬线标题与正文；品牌中文保留宋体。正文以 15–16 px 为主，标题按页面层级分为 21–48 px。
- 固定侧栏采用线性图标，首页突出继续课程与创建路线两个入口。
- 统一卡片、输入框、折叠区和按钮的边框、圆角与间距。阅读区保持适合长文的宽度。
- 学习路线、复习、测验、知识问答、模型设置及看板同步使用亮色；窄屏改为单列布局。

## 接口与逻辑边界

本轮只修改 presentation.py、workspace.css、workspace.js 的主题类处理，以及 dashboard.py 的图表颜色。没有新增接口，没有修改已有接口参数、数据库结构、模型调用、课程生成、复习算法、测验评分或权限逻辑。学习数据不作改写。

暗色界面暂不在本轮交付范围。前一版展示文件已另行备份。

## 验证

页面回归与浏览器验证结果见交付消息。模型服务使用原配置，本轮没有再次调用收费模型。此前向量检索的额度限制不属于此次视觉调整范围。

验证结果：35 项页面回归通过。浏览器核对首页、课程阅读、路线表单和知识问答；390px 宽度下首页卡片及路线表单切换为单列，页面宽度保持 390px，无横向溢出。改动通过 git diff --check。
