# Learn Everything 暗色界面与功能完善说明

更新日期：2026-10-17

项目：`F:\start_up\yi_tai\learn-everything`

## 设计参考与落实

- [Linear：A calmer interface for a product in motion](https://linear.app/now/behind-the-latest-design-refresh)：统一导航和操作的位置，降低侧栏的视觉权重，使当前任务突出。
- [Readwise Reader：Longform reading](https://docs.readwise.io/reader/guides/workflows/longform-reading)：以阅读内容为中心，低频操作和辅助面板按需展开。
- 沿用以太智元官网的宋体标题、暗色基底、克制的青灰色强调及知识分枝配图。没有新增亮色模式。

首页保留一个主要入口“进入学习工作台”，创建路线作为次级入口。导航按学习流程排列，并将知识资料、偏好设置分组。

学习工作台默认显示课程选择与正文；课程正文限制阅读宽度。环境配置、课程维护、添加课程集中在管理区域。AI 助教通过右上角入口展开，可通过关闭按钮或 Esc 收起。正文保留阅读、实践、笔记、参考四个入口，掌握状态放在正文末尾。

学习路线采用“定义学习目标—预览与保存”的两步结构。已有项目、导入导出和批量操作默认收起。复习和测验采用受控宽度的内容区域。知识问答将会话、文件和引用分别收进按需展开的面板。

## 接口与数据影响

没有新增对外 HTTP 接口，没有更改现有数据库表结构，没有修改 Kotaemon 子模块的基础代码。原有学习项目、课程、笔记、资料与事件绑定保留。

以下属于功能完善或已有问题修复，不只是视觉调整：

1. **复习闭环**：增加项目选择、卡片揭示与评分、AI 提炼卡片和手动添加卡片。评分使用既有 FSRS 服务，写入原有复习记录。未揭示答案时不能评分，重复提交不会重复评分。
2. **测验闭环**：支持生成、逐题作答、解析、历史记录与继续最近测验。生成结果验证知识点归属和题型结构；选择题本地判分，其余题型由模型反馈；避免重复提交产生重复记录。
3. **模型输出完整性**：模型返回长度截断时显示明确错误，避免将截断内容作为完整课程保存。GLM-5 系列为思考与正文预留输出空间；GLM-5.3 使用官方支持的 `reasoning_effort=low`。取消 SDK 与应用重试叠加，保留应用层有限重试。服务商地址、模型选择和用户密钥仍由现有配置管理。
4. **模型配置生效修复**：向量模型原先引用了不存在的管理器，导致保存后未同步启用。现在使用实际的 `embedding_models_manager`；更新失败会明确报告。
5. **路线与课程状态**：有效路线生成后才开放保存。切换项目时选择有效课程，避免空选项覆盖已加载状态。
6. **测试隔离**：测试项目写入临时数据库；普通页面测试不启动资料抓取后台任务，避免测试结束后继续写库或调用外部服务。

用户提供的模型凭据只保存在本机既有配置及模型管理数据中，本说明不记录凭据，代码中没有硬编码密钥。

## 验证结果

- 最终自动回归：135 项通过；7 项真实模型用例在默认测试中按设计跳过。
- 单独开启真实模型验证：普通聊天、结构化 JSON、学习路线、课程正文、环境清单、复习卡片、测验生成与评分均取得成功结果。
- 曾发现长课程请求因思考时间和嵌套重试长时间等待；修正参数后，课程正文用例再次通过，用时约 106 秒。实际速度仍取决于模型服务。
- 浏览器实测：课程助教返回真实回复，知识问答返回真实回复；助教的展开、关闭和焦点切换正常。
- 桌面布局检查完成。390px 视口下，路线输入与预览上下堆叠，内容宽 358px，页面未发生水平溢出。

## 当前外部限制

`embedding-3` 资料向量检索真实请求返回 HTTP 429 / 1113，服务商提示余额不足或没有可用资源包。因此文件索引和基于文件的向量检索尚不能宣称验收通过；需要账户开通可用额度，或在模型配置中改用有权限的兼容向量服务后再次验证。普通学习生成和问答已通过。

GraphRAG、LightRAG、Nano-GraphRAG 为底座的可选扩展，当前环境未安装其额外依赖，本次未安装这些扩展，也未将它们算作已验证功能。
