# 学习界面调整

本次无新增接口，无数据库结构或存量数据修改。测验生成、评分、复习算法和权限逻辑保持原样。

- 项目选项统一显示名称；空名称、单字符占位名称优先采用原始选题，仍无法识别则显示“未命名学习项目 · 编号”。仅显示转换，不重写项目。
- 课程选择器使用文字状态，正文仅清理标题中的装饰 emoji，保留数据库原文、代码块和笔记。
- 测验设置与作答区域分开，沿用原有事件绑定和参数。
- 看板使用现有统计显示进度条，日期图使用离散日期并从零开始绘制。
- 新增展示层下一步引导：有到期卡片时建议复习，有薄弱知识点时建议测验，否则进入工作台。按钮只切换现有页面，不生成内容、不修改记录；进入目标页后仍使用其原有项目选择。


## 学习时长范围与导出

新增本地页面事件 `_load_activity(project_id, days)` 与 `_export_activity(project_id)`，没有新增外部 HTTP API 或改动数据库结构。只读取当前用户、当前项目的 `study_minutes` 记录。

图表提供最近 3 天（默认）和 30 天，沿用现有 UTC 记录日期口径，缺失日期补零。图表改用响应式 HTML/CSS，移除 Plotly 工具栏和隐藏标签页初始化宽度问题。

“导出全部记录”生成 UTF-8 BOM CSV 下载文件，包含当前项目所有日期的学习时长原始记录；不受 3/30 天限制。无记录时显示说明，切换项目后清除旧下载入口。文件字段为记录编号、项目编号、知识点编号、UTC 时间、分钟数。不导出密钥、模型配置或课程正文。

## 操作引导
首页长说明替换为四步操作指引：连接模型、输入目标、预览保存、选择课程。指引切换现有页面并标记操作区域，支持上一步、下一步和退出（Escape），不会代填密钥、自动调用模型或保存项目。完整说明保留在帮助页折叠区。本次未新增后端接口或修改学习流程。

## 聚光灯与问答设置
引导增加跟随滚动和窗口尺寸的遮罩，退出时移除。问答设置统一中文显示名称，保留原始选项 value、选中值和已有回调；未更改默认语言、模型或思维导图开关。引用和思维导图随回答设置一起折叠。无新增后端接口。

## 渐进式路线与聊天菜单
学习路线改为方向、基础、目标、节奏四步；输入仍绑定原有 Gradio 控件，继续/返回仅切换展示，不持久化、不调用模型。最后点击生成才调用原有流程，结果仍需用户保存。聊天输入框下方新增资料、来源、思维导图和回答设置入口，点击显示现有设置控件；所有内部值与回调保持不变。

## 问答空会话与工具菜单
空会话居中显示标题和输入框；有消息后恢复对话布局。输入框左侧加号打开工具菜单，设置在二级面板中显示。沿用原有输入、发送、模型和检索控件，不新增接口或改变模型调用。

## 回答后的引用资料
移除工具菜单中的引用资料项，将原引用面板放在回答区域下方。依据聊天组件实际加载状态、回答和引用内容决定显示；生成中、空会话和无引用内容时隐藏。保留原有历史消息选择与引用更新回调，不新增接口。
