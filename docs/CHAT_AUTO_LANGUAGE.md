# 聊天模型入口与自动回答语言

模型选择移至知识问答页左上角，复用原有控件及回调。
回答语言选择从界面移除，回答设置改为检索方式。

## 行为变化

创建问答推理流程时，扩展层将 session_language 统一设为 auto。
语言提示为：优先遵循用户明确指定的语言，否则使用当前问题的语言，由模型判断。
旧会话保存的固定语言不再覆盖该策略。模型、检索范围及其他参数保持不变。

## 接口影响

没有新增或修改 HTTP 接口、数据库结构及凭据。变更位于 learning_ext，未修改 Kotaemon 底座。
新增内部语言标识 auto，映射为提示词中的自动语言说明。语言选择是模型行为，不能保证每次输出都严格遵循。
