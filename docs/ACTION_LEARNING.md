# 工作台 · 逐步行动

入口：学习工作台 → 课程标题下的「拆解步骤」。入口固定排在正文之前，不随长文被推到底部。原来的阅读、实践、笔记和过关流程仍然保留。

点击后立即进入拆解加载页；成功后一次呈现一条行动。当前行动旁直接提供「给我一点提示」「问问 AI」「屏幕引导」。AI 提问支持回车发送。返回全文后焦点回到拆解入口；失败时恢复阅读并显示可重试的原因。

## 教学行为

首次进入使用当前模型，根据学习目标、背景、项目课程列表、当前课的完整正文和实践内容，生成小行动。每条包含具体动作、可观察的完成标准、提示和原文依据。生成失败可重试，不把任意段落截断后伪装成行动方案。

专注视图一次显示一条行动，上下提供淡化的相邻步骤导航。前后切换只是浏览；“这一步我做完了”记录为用户自行确认，不修改课程掌握度，不绕过已有过关检查。相同用户、课程和内容可以恢复步骤位置；课程或背景变化后重新生成。

## 动手学辅助

使用 `learning_ext/agent` 的本地 Windows 执行基础，新增限定窗口的 UI Automation 适配器。AI 文字解释带完整课程背景，但只回答当前一步的问题。

1. 用户刷新并选择目标窗口。窗口绑定句柄、进程、进程启动时间和标题。
2. “读取这个窗口的控件”只本地读取可访问控件；不截屏、不读取密码框或输入框内容。
3. 可手动选择控件，或明确允许将控件名称发送给界面标明的模型来定位。模型只能返回列表中的控件标识，不能给出任意坐标或执行代码。
4. 先显示 6 秒的蓝青色圈选。覆盖层鼠标穿透、不抢焦点，随目标控件移动；目标失效即关闭。
5. 圈选后才出现当前窗口、当前控件的一次性授权。有效期 90 秒。每次操作后消费授权，失败也不能重复使用。
6. 操作前再次匹配窗口身份和控件 RuntimeId、名称、类型、动作。只调用标准的 Invoke / Toggle / Select / Expand，不发送全局鼠标或键盘、不运行模型生成的命令。
7. 切换步骤、退出专注模式、换窗口、换控件和停止辅助都会撤销授权。需要再次操作时重新定位。

当前支持提供标准 UI Automation 控件的 Windows 软件。自绘界面、部分浏览器内容、权限提升窗口可能读不到，显示无法定位并保留文字辅助。没有像素视觉模型或任意桌面代理能力。涉及发送、付款、删除、安装、权限等按钮只提供定位；代码、命令和输入内容由用户自己执行。圈选是否能在目标窗口上可见取决于该窗口的可访问性和显示状态，不能把成功发起圈选当作学习验收。

## 后台记录

默认保存到 `output/runtime/action-learning.sqlite3`，不提交到 Git。

- `sessions`：用户、课程、内容指纹、行动方案、当前位置和自行完成的步骤。
- `events`：时间、会话、课程、步骤、事件类型与 JSON 详情。包含生成/失败、恢复、浏览、提示、AI 请求与回复、窗口观察、定位、圈选、授权/拒绝/撤回、操作结果与退出。
- 日志隐藏常见 API Key、Bearer、token、password 字段。默认不存截图、整屏内容或输入框内容；课程方案和主动提问按学习记录保存在本机。
- 授权和待执行动作只在当前 Gradio 会话内保留，不落盘恢复。日志无法写入时不会执行电脑操作。

可用 SQLite 工具查看事件；按 `session` 关联课程方案。首次拆解依赖当前模型服务，后续浏览、提示和手动圈选不调用模型。

## 本轮验证

- 针对性回归覆盖生成格式与原文引用、用户/课程隔离、恢复进度、提示上下文、HTML 转义、定位失败、授权过期、跨步骤、重复执行、窗口身份变化和日志写入失败。
- 使用现有 Python 课程实际生成 24 条行动；验证提示、相邻步骤导航、返回全文、重启后恢复，以及当前步骤的模型问答。
- 在独立桌面练习窗口验证 UI Automation 读取和单次授权点击：未授权被拒绝，授权一次后实际窗口反馈发生变化，授权随后清空。后台 `events` 已写入拒绝、批准与结果。
- 原生练习窗口同步改为蓝青主题、三步进度、圆角输入与按钮、反馈卡和可拖动的自定义标题栏。保留 GoalInput 和检查/撤销控件名称；真实输入、检查与撤销通过。常规练习结果还会进入后端运行日志。
- `scripts/render_practice_preview.ps1` 从同一 XAML 离屏渲染界面设计预览，不把预览图当作桌面执行证据。
